# Fonte, atribuição e evidências

Wide World Importers é uma empresa fictícia. Os dados sintéticos e trechos de código da Microsoft são usados neste case de portfólio; os resultados não pertencem à experiência profissional do autor.

O código oficial copiado em `data/metadata/`, inclusive `embedded_modules/`, e as descrições extraídas mantêm a atribuição à Microsoft. A [licença MIT da fonte](data/metadata/microsoft-license.txt) acompanha essas cópias. A [release oficial](https://github.com/microsoft/sql-server-samples/releases/tag/wide-world-importers-v1.0) e o [manifesto](data/metadata/source_manifest.json) identificam o artefato. O backup e os arquivos do banco não são distribuídos neste repositório. Os avisos das fontes geográficas permanecem na documentação oficial preservada.

Não foi escolhida uma licença de reutilização para o código autoral deste projeto. A licença da Microsoft se aplica ao material da Microsoft; não deve ser interpretada como uma licença automática de todo o repositório.

As evidências históricas contêm nomes da instância, identificadores de sessões, caminhos de desenvolvimento e identificação da máquina/conta local. São contexto de execução, não credenciais nem arquivos pessoais anexados. Esses registros foram preservados, com seus hashes, em vez de sanitizados silenciosamente. Caminhos históricos não são requisitos de instalação: os runners resolvem a raiz do projeto a partir da localização dos scripts. As conexões locais usam autenticação integrada do Windows, sem senha embutida.

`stage4-closeout.json` registra o estado anterior à publicação. Os hashes de arquivos alterados justificadamente no fechamento pré-publicação não serão reescritos nesse registro; o histórico Git passa a registrar as mudanças posteriores. SQL, contrato e evidências de testes permanecem inalterados. Atributos Git preservam os bytes auditados durante clone/checkout.

O desenvolvimento teve apoio de IA. As decisões analíticas, limitações e evidências estão documentadas para revisão técnica; nenhuma análise comercial futura é apresentada como concluída.
